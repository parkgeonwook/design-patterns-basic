# design-patterns-basic

GoF의 23가지 디자인 패턴을 학습하기 위한 **기초** 예제입니다.

## 학습 범위
이 프로젝트는 각 디자인 패턴의 가장 기본적인 개념과 구조를 이해하는 데 목적이 있습니다.

복잡한 확장 방식이나 심화 구현보다는, 패턴이 무엇인지 처음 익힐 수 있는 기초적인 예제를 중심으로 정리합니다.

## 디자인 패턴 분류

### 생성 패턴 (creational)
- Singleton
- Factory Method
- Abstract Factory
- Builder
- Prototype

### 구조 패턴 (structural)
- Adapter
- Bridge
- Composite
- Decorator
- Facade
- Flyweight
- Proxy

### 행위 패턴 (behavioral)
- Chain of Responsibility
- Command
- Interpreter
- Iterator
- Mediator
- Memento
- Observer
- State
- Strategy
- Template Method
- Visitor
