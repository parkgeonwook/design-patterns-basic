## 플라이웨이트를 사용하지 않을 때
### 같은 정보가 반복되어도 객체를 계속 새로 만들 수 있다.

예를 들어 같은 문자 `A`를 여러 번 사용해도

- `A` 객체 생성
- 또 `A` 객체 생성
- 또 `A` 객체 생성

처럼 중복된 객체가 계속 생길 수 있다.

이 경우 공통 정보가 많을수록 메모리 낭비가 커질 수 있다.

## 플라이웨이트를 사용할 때
### 공통 객체를 공유해서 재사용할 수 있다.

같은 문자 `A`를 여러 번 요청하더라도  
이미 만들어진 `A` 객체가 있으면 그것을 다시 사용한다.

- 문자 자체 정보는 공유
- 위치 같은 값은 따로 전달


예를 들어 `A` 객체 하나를 공유하면서

- `(1, 1)` 위치에 출력
- `(2, 3)` 위치에 출력

처럼 사용할 수 있다.
