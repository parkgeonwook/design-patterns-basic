## 커맨드 패턴을 사용하지 않을 때
### 호출하는 쪽이 어떤 객체의 어떤 메서드를 실행할지 직접 알아야 할 수 있다.

예를 들어 리모컨이 전등을 켜려면

`light.on()`

처럼 직접 호출해야 한다.

이 경우 호출하는 쪽이 실제 작업 대상과 메서드를 알아야 하므로 실행 방식이 바뀌거나 작업 종류가 늘어나면 코드가 복잡해질 수 있다.

## 커맨드 패턴을 사용할 때
### 실행할 요청 자체를 객체로 분리할 수 있다.

예를 들어

- `LightOnCommand`
- `FanOnCommand`

처럼 명령을 각각 객체로 만든다.

그러면 호출하는 쪽은 실제 작업 내용을 몰라도 그냥 `execute()`만 호출하면 된다.

즉, 요청을 객체로 다루면서 실행 대상과 호출하는 쪽을 분리할 수 있다.

## 정리
커맨드 패턴은 실행할 요청을 객체로 만들어서 요청 자체를 전달하고 실행할 수 있도록 하는 패턴이다.

이 패턴을 사용하면 호출하는 쪽과 실제 작업하는 쪽을 분리할 수 있고 실행 요청을 저장하거나 바꿔 끼우거나 나중에 실행하는 구조로 확장하기도 쉽다.
